## 数据与状态

`controlled_document` 为目录和当前版本指针，`document_revision` 保留每版纯文本正文、变更说明、审批和日期；`revision_recipient` 保留送审接收范围；`read_assignment` 为版本阅读任务；`document_event` 为业务历史；`command_stamp` 为幂等记录。管理表提供账号、角色、权限、部门、字典、菜单、参数和审计。

目录：ACTIVE → RETIRED。修订：DRAFT → REVIEW → APPROVED → PUBLISHED；退回为 REJECTED，保存后回 DRAFT；撤回审批回 DRAFT；未发布修订可以撤销为 WITHDRAWN。换版将原生效版变 SUPERSEDED；归档将当前版变 WITHDRAWN。

阅读任务：PENDING → ACKNOWLEDGED；换版/归档停止未签收任务，变 SUPERSEDED/WITHDRAWN。已签收记录不改写。

所有业务修改处于同一事务，锁定目录行，校验 `version`。事件递增 `changeCount` 保证版本号变化，发布和签收互斥；命令以目录、账号和请求键唯一，载荷摘要不同则拒绝重用。幂等是当前权限和数据范围内的重试，不赋予额外权限。

## 认证

GET `/api/auth/csrf` 返回 CSRF header/token，POST `/api/auth/login` 提交 username/password，后续依赖同源 Cookie。GET `/api/auth/me` 获取实时账号、权限和菜单；POST `/api/auth/logout`、POST `/api/auth/password` 支持退出与改密。Cookie 为 HttpOnly、SameSite=Strict，30 分钟会话；正式 HTTPS 开启 Secure。

## 业务端点

| 方法及路径（前缀 `/api`） | 内容 |
| --- | --- |
| GET `/options` | 当前部门范围内人员、字典、系统参数 |
| GET `/documents` | search / status / category / page / size / sort；sort 仅 newest/title/number |
| POST `/documents` | title、category、departmentId、ownerId；新建目录及 R1 |
| GET `/documents/{id}` | 授权版本、签收、事件及允许命令 |
| DELETE `/documents/{id}?version=N` | 仅新建未送审单份草稿 |
| POST `/documents/{id}/revisions` | version，开始下一份修订 |
| PUT `/documents/{id}/revisions/{rid}` | version、title、content、changeSummary、reviewerId、effectiveDate、reviewDate、acknowledgementDue、recipients |
| POST `/documents/{id}/revisions/{rid}/{action}` | submit/recall/approve/reject/withdraw/publish/distribute |
| POST `/documents/{id}/retire` | 归档，须 note |
| POST `/documents/{id}/assignments/{aid}/acknowledge` | contentHash，签收本人当前任务 |
| GET `/workbench` | 本人修订审批及阅读待办 |
| GET `/dashboard` | 范围内指标 |
| GET `/audit` | 授权审计记录 |
| GET `/documents/{id}/report.json` | 授权 JSON 快照，不加入推广内容 |

命令载荷：version、requestKey（8–80 位字母数字下划线横线）、note；分发额外使用 recipients、dueDate。普通保存和创建修订使用乐观版本，流转命令还有幂等校验。日期为 YYYY-MM-DD，时间返回 ISO 时间戳。errors 只返回安全错误代码。

## 系统管理

GET/POST `/admin/{type}`、PUT/DELETE `/admin/{type}/{id}`，type 为 users/roles/departments/menus/permissions/dictionaries/settings。创建删除仅支持 users/roles/departments/dictionaries；其他是注册资源字段编辑。缺权限返回 403；冲突、过期版本或错误状态返回 409；输入错误返回 400。

ALL 查看全部部门；DEPARTMENT 仅本部门；ASSIGNED 仅同部门中本人作为建档人、目录责任人、版本作者/审批人或签收人员参与的目录。纯阅读角色看不到从未发布目录或未发布修订；签收只返回自身记录，除非有审计权限或是具备发布权限的目录责任人。服务端不信任界面隐藏状态。
