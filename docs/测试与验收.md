## 可重复运行的检查

后端：Java 21 / Maven 3.9，`mvn -B spotless:check clean verify`；测试配置仅使用 H2 的 MySQL 模式，动态生成强密码，不依赖本机业务库。7 个规则测试覆盖陈旧版本、三方独立审批、日期顺序、缺失日期、Unicode 摘要、状态和 BCrypt 字节限制；26 个 HTTP 集成测试覆盖完整发布签收、隐私范围、跨部门、作者权限、输入、冻结、未来生效、换版证据、幂等、并发、归档、统计、管理保护、CSRF 和改密。

前端：`npm ci`、`npm run format:check`、`npm run lint`、`npm test`、`npm run build`。6 个测试覆盖同源 CSRF、会话过期、时区以及当前版本本人签收入口。测试不替代服务端授权。

Compose：`docker compose config --quiet`、`docker compose build`、`docker compose up -d --wait`。镜像内执行格式、测试和构建，不跳过 Maven 测试。只有 MySQL/H2 两类实际验证都完成才能判定数据库可运行。

真实 MySQL 流程：在隔离的本机测试库执行 `python3 scripts/smoke.py --allow-test-data`。脚本生成独立部门、账号和标明验收的虚构正文，验证审批退回、批准发布、个人签收、换版失效、证据留存、权限隔离、幂等、搜索、报表和统计。不要在生产环境执行。

`python3 scripts/smoke.py --allow-test-data --verify-existing ID` 可验证重启后已发布快照仍存在。完整数据库迁移记录和系统健康需额外查看实际测试部署。

发布检查：`python3 scripts/release-check.py` 检查源码署名、README 图片、两个原二维码和 LICENSE 摘要、常见敏感模式。该模式扫描不等于专业安全审计；人工差异检查是另一项必要检查。

## 验收范围与限制

截图必须由实际运行页面采集，业务内容为隔离测试资料；页面验收覆盖不同账号写入、审批、发布、阅读、语言切换、管理与窄屏。日期边界由测试时钟验证，页面显示采用部署配置的实际时区。

尚无负载测试、渗透测试、跨浏览器全面兼容或行业合规认证。没有测试第三方 SSO、通知、电子签名或 AI 功能，因为本版未实现这些功能。发布的检查结果与证据另列首版验收记录。
